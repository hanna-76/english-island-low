# 英语奇趣岛（低档版）— 3~5岁儿童听音找图

> 面向 3~5 岁低龄儿童的英语启蒙 H5 小游戏，核心玩法为"听音找图"，支持手机触控操作。

## 项目简介

本项目是"儿童英语学习小游戏"实训的低档版本，专注于完成核心游戏流程和手机触控操作。儿童通过听单词发音，从多张图片中选出正确答案，在游戏中积累英语词汇。

## 功能特性

### 核心玩法
- **听音找图**：播放单词发音，儿童从图片中选出正确答案
- **3 个主题**：动物、水果、颜色，每个主题 10 个单词，合计 30 个词汇卡片
- **每轮 10 道题**：题目顺序随机变化
- **每题 2 张图片**：低龄儿童友好，降低选择难度

### 游戏流程
1. **首页**：游戏标题 + 开始按钮
2. **主题选择**：选择动物 / 水果 / 颜色主题
3. **听音答题**：播放发音，选择图片
4. **答题反馈**：答对变绿鼓励，答错变红提示
5. **得分结算**：显示星星数量和正确率
6. **重新开始**：可重玩当前主题或返回选主题

### 交互设计
- **重播发音**：每题可点击"再听一次"重复播放
- **答错重试**：答错后允许再次选择，不设置倒计时
- **手机触控**：大按钮、大图片，适配手指点击
- **纯颜色块**：颜色主题使用纯 CSS 颜色块，比 emoji 更准确

## 技术方案

### 发音方案
使用**有道翻译 TTS 在线接口**播放英语发音：
- 接口：`https://dict.youdao.com/dictvoice?audio=单词&type=2`
- type=1 英式发音，type=2 美式发音
- 优点：不依赖浏览器语音合成，微信 / 安卓浏览器 / iOS 都能发音
- 备用方案：在线接口失败时回退到浏览器 Web Speech API

### 答题防重复点击
- 使用 `locked` 变量防止一题内重复点击
- 使用 `timer` 变量管理 setTimeout，每次设新定时器前 clearTimeout
- 答错后 0.8 秒高亮正确答案，2 秒自动进入下一题

## 本地运行

### 方式一：直接打开
双击 `index.html` 即可在浏览器中运行。

### 方式二：本地服务器（推荐）
```bash
# 进入项目目录
cd english-island-low

# 启动本地服务器（Python）
python -m http.server 8000

# 浏览器访问
# http://localhost:8000
```

### 手机测试
1. 电脑和手机连接同一 WiFi
2. 查看电脑 IP 地址（Windows：`ipconfig`）
3. 手机浏览器访问 `http://电脑IP:8000`

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库 `english-island-low`
2. 上传所有文件到仓库根目录
3. 仓库 Settings → Pages → Source 选择 `main` 分支 → Save
4. 访问 `https://你的用户名.github.io/english-island-low/`
